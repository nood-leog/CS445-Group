# CS445 Group 2

This project aims to sort and visualize trends in the Connecticut legal cannabis market using available sources. 

This project includes two directories containing a variety of data files.
>**/data/**
>>Includes all relevant data to the visualizations within this project.

>**/extra_data/**
>>Includes data that may be relevant to the topic, but was not utilized for visualization.

#AA_Cannabis_Retail_Products_Sold_by_Product_Type.csv
#Contains data on the quantity and types of cannabis products sold by retail stores, categorized by product type.
#Other category includes:Other (Pill, Capsule, Non Smokable Infused Extract, Tincture, Marijuana Infused Topicals, Liquid Marijuana RSO, Marijuana Mix Infused, Lozenge)

#BB_Average_Price_Per_Gram_of_Usable_Cannabis.csv
#Shows the average price per gram for usable cannabis, likely broken down by time period or region.

#CC_Cannabis_Retailers1.csv
#Lists cannabis retailers, possibly including names, locations, and license information.

#DD_Licensed_Cannabis_and_Medical_Marijuana_Retail_Locations.csv
#Provides details on licensed retail locations for both recreational and medical marijuana, including addresses and license status.

#EE_Cannabis_Brand_Registrations_By_Type.csv
#Contains information about registered cannabis brands, categorized by type (e.g., flower, edibles, concentrates).

#FF_Cannabis_Retail_Sales_by_Week_Ending.csv
#Reports retail cannabis sales figures, aggregated by week.

#GG_Number_of_Medical_Marijuana_Registrants_by_Month.csv
#Tracks the number of medical marijuana registrants, reported monthly.

#HH_Medical_Marijuana_Dispensary_License1.csv
#Lists medical marijuana dispensaries with license details and possibly other identifying information.

#II_Medical_MarijuanaCannabis_Brands_with_Chemical_Composition1.csv
#Details cannabis brands along with their chemical composition (e.g., THC/CBD content)
